# 📚 HTML CSS JavaScript 前端教程 PPT

一个包含 **60 页**的前端开发教程演示文稿，涵盖 HTML、CSS 和 JavaScript 三大核心技术。

## 📖 内容大纲

| 部分 | 页码 | 主题 |
|------|------|------|
| **Part 1** | 第 1-20 页 | **HTML 基础** — 文档结构、常用标签、表单、语义化、HTML5 |
| **Part 2** | 第 21-40 页 | **CSS 样式** — 选择器、盒模型、Flexbox、Grid、响应式、动画 |
| **Part 3** | 第 41-60 页 | **JavaScript** — 语法、DOM、事件、ES6+、异步编程、实战 |

## 🚀 使用方法

1. 直接在浏览器中打开 `index.html` 文件
2. 使用以下方式翻页：
   - **键盘**：← → 方向键 或 空格键
   - **鼠标**：点击底部导航按钮
   - **触屏**：左右滑动

## ✨ 特性

- 纯 HTML + CSS + JS 实现，无需任何依赖
- 响应式设计，支持桌面和移动设备
- 支持键盘、鼠标和触屏操作
- 顶部进度条显示阅读进度
- 自动保存浏览位置（刷新后恢复）
- 四种主题配色（标题页、HTML、CSS、JavaScript）
